    Los ROMs viven en `public/roms`, pero el publico ya no podra abrirlos directo: el Worker solo los entrega con una NFC key valida.

    Flujo nuevo
    1. Elige el core y sube el ROM desde aqui.
    2. El Worker lo guarda en GitHub dentro de `public/roms/...`.
    3. `public/roms/catalog.json` se actualiza automaticamente.
    4. La ruta del juego se llena sola para la nueva NFC.
